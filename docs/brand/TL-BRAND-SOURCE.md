# Taco Loco — Brand Source

## Source

- File: `manual tacoloco.pdf`
- Format: one-page Adobe Illustrator PDF supplied by the owner.
- Extraction: rendered page at 180 DPI; the approved green swatch was cropped without the surrounding headings, borders, typography samples or `CREADO POR / @blu.creativo` credit, then encoded as WebP.
- Extracted asset: `public/brand/taco-loco-pattern-green.webp` (302×336, WebP, approximately 20 KB).

## Approved hierarchy

- Primary brand pattern: green skull pattern.
- Secondary accent: yellow.
- Limited accent / alert: red.
- The pattern is decorative and must sit behind or beside clean readable surfaces, not behind dense operational content.

## Typography

The manual shows Poppins and Bebas Neue. No approved local font files are currently present, so this implementation keeps the existing system font stack and records the font asset as deferred. No third-party font request was added.
